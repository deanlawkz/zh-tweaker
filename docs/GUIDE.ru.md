## Коротко: что нужно

| Что | Требование |
|---|---|
| Компьютер | Мак на Apple Silicon (M1, M2, M3, M4 и новее) |
| Система | macOS 15 Sequoia или новее (это требование GeneralsX) |
| Игра | GeneralsX и данные Zero Hour из своей лицензионной копии |
| Node.js | 22.13 или новее; если нет, установщик скачает его сам |
| Интернет | Только для установки и обновления |
| Права администратора | Не нужны, `sudo` не используется |

## Установка шаг за шагом

1. Убедитесь, что Generals Zero Hour уже запускается через GeneralsX. Если нет, начните с раздела [«У меня ещё нет игры на Маке»](#у-меня-ещё-нет-игры-на-маке).
2. Откройте **Терминал**: Launchpad → Другие → Терминал, или Cmd+Пробел и наберите «Терминал».
3. Вставьте команду и нажмите Enter:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/deanlawkz/zh-tweaker/main/install.sh | bash
   ```

4. Дождитесь строки «Готово». Если Node.js не было, установщик скачает около 50 МБ.
5. В Программах появится значок **ZH Tweaker** с портретом командного центра.

Что делает установщик:

- кладёт программу в `~/Library/Application Support/ZH Tweaker/app`;
- если подходящего Node.js нет, скачивает официальную сборку с nodejs.org, проверяет контрольную сумму и кладёт её в `~/Library/Application Support/ZH Tweaker/node`. Системный Node.js он не трогает;
- создаёт значок в `/Applications`, а если туда нельзя писать, в `~/Applications`;
- проверяет, найдена ли игра, и предупреждает, если нет.

## Первый запуск

1. Откройте **ZH Tweaker**. В браузере откроется страница http://127.0.0.1:4170. Она работает только на вашем Маке, в интернет ничего не уходит.
2. Выберите юнит или здание. Вверху карточки главные цифры: здоровье, скорость, цена, время постройки, обзор, места внутри, энергия, доход. Нажмите на число, введите новое и нажмите Enter.
3. Ниже есть все остальные поля с понятными подписями, а также кнопки «Взять у другого» (перенести способность от другого юнита) и «Текст целиком» (для опытных).
4. Вкладка **«Что строят здания»** меняет кнопки постройки: любой юнит можно добавить в любое здание.
5. Вкладка **«Оружие»** меняет урон, дальность, перезарядку, снаряды.
6. Вкладка **«Камера и общее»**: высота камеры до 690, стрельба пассажиров во все стороны, дым и звук ракет в больших боях.
7. Нажмите **Применить**, затем **Играть**. В лобби схватки выберите себе фракцию **Commander**.

Все правки видны на вкладке **«Изменения»**, по юнитам, в виде «было → стало». Любую можно отменить. Правки касаются только Commander: обычные фракции и компьютерные противники играют по стандартным правилам.

## У меня ещё нет игры на Маке

ZH Tweaker не содержит игру и не скачивает её. Нужна своя лицензионная копия, например из Steam (Command & Conquer: Generals Zero Hour) или из EA App.

1. Установите **GeneralsX**: скачайте сборку для macOS со страницы [выпусков GeneralsX](https://github.com/fbraz3/GeneralsX/releases), распакуйте и перенесите приложение в Программы. При первом запуске macOS может его заблокировать: откройте Системные настройки → Конфиденциальность и безопасность и нажмите «Всё равно открыть».
2. Положите данные игры в папки:
   - Zero Hour: `~/GeneralsX/GeneralsZH`
   - обычная Generals: `~/GeneralsX/Generals`
3. Где взять данные, подробно описано в [вики GeneralsX](https://github.com/fbraz3/GeneralsX/wiki/Getting-the-Game-Files). Самые частые способы:
   - скопировать папку игры с Windows-компьютера, где она установлена через Steam;
   - скачать через SteamCMD (в Steam для Мака кнопки «Установить» у этой игры обычно нет). Номер Zero Hour в Steam: 2732960, обычной Generals: 2229870.

Твикеру нужны файлы `*.big` в папке Zero Hour. Папка обычной Generals тоже желательна: из неё берутся часть картинок и надписей.

## Мак на Intel

GeneralsX выпускается только для Apple Silicon. На Маке с процессором Intel игра не запустится, поэтому и твикер там бесполезен. Установщик Node.js для Intel поддерживает, но это не поможет без игры.

## Игра лежит в другой папке

Проще всего сделать ссылку на стандартное место. Тогда и GeneralsX, и твикер найдут игру:

```bash
mkdir -p ~/GeneralsX
ln -s "/путь/к/папке/Zero Hour" ~/GeneralsX/GeneralsZH
ln -s "/путь/к/папке/Generals" ~/GeneralsX/Generals
```

Если ссылка не подходит, запускайте твикер с указанием папок:

```bash
cd ~/Library/Application\ Support/ZH\ Tweaker/app
ZHT_GAME_ZH="/путь/к/Zero Hour" ZHT_GAME_GEN="/путь/к/Generals" node src/server.js
```

Если команда `node` не найдена, замените её на `../node/bin/node` (это Node.js, который скачал установщик). Потом откройте http://127.0.0.1:4170. Окно Терминала держите открытым, пока пользуетесь твикером.

## Русская и другие языковые версии

- **Английская версия** проверена, работает полностью.
- **Русификатор GeneralsX** (файл `00RussianZH.big` в папке Zero Hour) ставится поверх английской версии. Твикер берёт надписи из того же архива, поэтому русские названия должны сохраниться. Это не проверялось; если увидите странные подписи, напишите нам.
- **Немецкая и другие версии**: твикер пишет надписи в `Data/English/generals.csf`. Игра другой языковой версии может их не прочитать. Тогда у Commander вместо названий будут служебные метки вроде `OBJECT:...`. Играть это не мешает.
- Сам твикер работает на русском и английском. Язык меняется кнопкой EN/RU справа вверху.

## Значок не открывается или пишет «не запустился»

1. Посмотрите, что написано в окне: туда выводятся последние строки журнала. Полный журнал лежит в `~/GeneralsX/zh-tweaker/server.log`.
2. **«Не найдены файлы Zero Hour»**: игра лежит не там, см. [«Игра лежит в другой папке»](#игра-лежит-в-другой-папке).
3. **Порт 4170 занят** другой программой. Узнать какой:

   ```bash
   lsof -nP -iTCP:4170 -sTCP:LISTEN
   ```

   Закройте эту программу или перезагрузите Мак.
4. **Браузер не открылся**, хотя твикер работает: откройте http://127.0.0.1:4170 вручную.
5. **Значок пропал или сломался**: запустите команду установки ещё раз, она всё восстановит.

## В лобби нет фракции Commander

- Нажмите **Применить** и дождитесь сообщения без ошибок.
- Полностью закройте игру (Cmd+Q) и откройте снова: игра читает файлы только при запуске.
- Commander доступен в схватке (Skirmish). В кампании его нет.

## Игра вылетает после «Применить»

1. Откройте твикер и нажмите **Сбросить всё**. Это убирает из игры все файлы твикера и возвращает камеру. Игра снова станет стандартной.
2. Если твикер не открывается, удалите его командой из раздела [«Удаление»](#удаление): она тоже убирает файлы из игры.
3. Включайте правки по частям и ищите ту, после которой игра падает. Чаще всего виноваты слишком большие числа или ручная правка в «Текст целиком».
4. Напишите нам: см. [«Сообщить об ошибке»](#сообщить-об-ошибке).

## Сетевая игра, повторы и сохранения

- **По сети с правками играть нельзя.** У соперника другие данные, игра рассинхронизируется. Перед сетевой игрой нажмите **Сбросить всё**, после неё снова **Применить**: ваши правки сохранятся в твикере.
- **Повторы** (replays), записанные с правками, без тех же правок не воспроизведутся правильно.
- **Сохранения** схватки с Commander надёжнее загружать с теми же правками, с которыми они сделаны. После изменения правок старое сохранение может не загрузиться.

## Обновление твикера, игры или GeneralsX

- **Твикер**: запустите команду установки ещё раз. Ваши правки (`~/GeneralsX/zh-tweaker/tweaks.json`) не трогаются.
- **GeneralsX или файлы игры** обновились: откройте твикер и нажмите **Применить** ещё раз.
- После обновления GeneralsX настройки камеры может вернуть сама игра: снова нажмите **Применить**.

## Перенести или показать правки другу

Все правки лежат в одном файле `~/GeneralsX/zh-tweaker/tweaks.json`.

1. Скопируйте его на другой Мак в ту же папку (сначала установите там твикер).
2. Откройте твикер и нажмите **Применить**.

Через Finder в эту папку можно перейти так: Finder → Переход → Переход к папке → `~/GeneralsX/zh-tweaker`.

## Моды: Contra, TEOD и другие

Пока твикер работает только с обычной Zero Hour. Поддержка Contra и The End of Days в планах. Если мод установлен в ту же папку, твикер может прочитать его файлы вперемешку с обычными: сначала уберите мод.

## Безопасно ли запускать команду из интернета

Команда скачивает и выполняет скрипт [install.sh](https://github.com/deanlawkz/zh-tweaker/blob/main/install.sh). Его можно прочитать заранее:

```bash
curl -fsSL https://raw.githubusercontent.com/deanlawkz/zh-tweaker/main/install.sh | less
```

Что важно знать:

- скрипт не просит пароль и не использует `sudo`;
- пишет только в `~/Library/Application Support/ZH Tweaker`, `~/GeneralsX/zh-tweaker` и значок в Программах;
- скачивает файлы только с github.com и nodejs.org, Node.js проверяется по контрольной сумме;
- архивы игры (`*.big`) твикер только читает и никогда не меняет;
- страница твикера доступна только с вашего Мака (адрес 127.0.0.1), запросы с чужих сайтов отклоняются.

## Удаление

```bash
curl -fsSL https://raw.githubusercontent.com/deanlawkz/zh-tweaker/main/uninstall.sh | bash
```

Команда убирает файлы твикера из игры (как «Сбросить всё»), значок и саму программу. Ваши правки остаются в `~/GeneralsX/zh-tweaker`. Чтобы удалить и их:

```bash
curl -fsSL https://raw.githubusercontent.com/deanlawkz/zh-tweaker/main/uninstall.sh | bash -s -- --all
```

## Windows и Linux

Твикер сделан и проверен только для Мака. На Windows для Zero Hour есть свои редакторы и моды.
